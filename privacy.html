سياسة خصوصية موقع نايل شات

آخر تحديث: 3 نوفمبر 2026. تسري هذه السياسة على الموقع التعريفي المستضاف على GitHub Pages، ولا تمثل سياسة تطبيق Android نفسه.

1. المعلومات التي نجمعها

عندما تختار إرسال رسالة عبر نموذج الدعم، نستقبل الاسم وعنوان البريد الإلكتروني ونوع الرسالة وعنوانها ومتنها. لا تتطلب المراسلة إنشاء حساب على GitHub. لا تضع أرقام سرية أو كلمات مرور أو محتوى محادثات خاصة في الرسالة.

2. الغرض من الاستخدام

تُستخدم معلومات النموذج لتلقي الشكاوى، معالجة الأخطاء التقنية، دراسة الاقتراحات والتواصل مع المرسل عبر بريده الإلكتروني. لا يستخدم الموقع نموذج الدعم لنشر الرسائل علناً أو لعرضها للزوار.

3. التخزين ومن له حق الاطلاع

تُحفظ رسائل الدعم في مشروع NileChat على خدمة Supabase. تقيّد سياسات الوصول على مستوى الصفوف الاطلاع والتعديل بالحسابات المصرح لها كمديري دعم. يمكن لزوار الموقع إرسال رسالة جديدة، لكن ليس لديهم حق عرض الرسائل أو تعديلها.

4. خدمات الجهات الأخرى

  • GitHub: يتم طلب بيانات الإصدارات العامة وروابط APK من GitHub، وقد تنتقل إليه عند التنزيل أو فتح رابط بلاغ اختياري.
  • Supabase: معالجة وتخزين رسائل الدعم والتحقق من هوية مدير الدعم.
  • GitHub Pages: يستضيف ملفات الموقع ويعالج طلبات الوصول إليها وفق سياسات GitHub.

5. التخزين داخل المتصفح

يحتفظ المتصفح باختيار اللغة والمظهر ونسخة مؤقتة من بيانات الإصدارات وآخر وقت إرسال للمساعدة في منع التكرار. ولا يستخدم الموقع أدوات تحليلات إعلانية في هذا الإصدار. قد تعالج جهات الاستضافة سجلات تقنية وفق سياساتها.

6. الاحتفاظ والحذف

تُحتفظ رسائل الدعم بقدر ما يلزم لمتابعة الطلبات وتنظيم السجل. لم تُحدد مدة حذف تلقائي ثابتة لهذا النظام. يمكنك طلب تصحيح أو حذف رسالتك عبر نموذج التواصل باستخدام البريد نفسه، وستتم مراجعة الطلب والتحقق من علاقتك بالرسالة قبل التنفيذ.

7. حماية المعلومات

يستخدم الموقع اتصال HTTPS إلى خدماته، وقواعد منع القراءة العامة في Supabase. لا توجد ضمانة مطلقة لأي نظام متصل بالإنترنت؛ لذلك تجنّب إرسال محتوى حساس.

8. خصوصية تطبيق أندرويد

تتطلب ممارسات التطبيق الفعلية (المحادثات والمكالمات والوسائط والإشعارات والاحتفاظ بالبيانات) سياسة مستقلة مبنية على مراجعة الشيفرة وإعدادات الخدمات، ولا تغطيها هذه الصفحة.

9. التواصل والتغييرات

لأي استفسار أو طلب متعلق ببيانات الموقع، استخدم نموذج الدعم. قد تُحدّث هذه الصفحة عند تغيير وظائف الموقع أو الخدمات المستخدمة، وسيظهر تاريخ آخر تحديث.

NileChat Website Privacy Notice

Last updated: 3 November 2026. This notice covers the informational website hosted on GitHub Pages, not the separate Android application's data practices.

1. Information collected

If you submit the support form, we collect your name, email address, category, subject and message. No GitHub account is required. Do not include passwords, sensitive identifiers or private conversation contents.

2. How information is used

Support information is used to receive bug reports, consider suggestions and contact you regarding your request. Support messages are not published publicly by the website.

3. Storage and access

Support messages are stored in NileChat's Supabase project. Database row-level security restricts reading and updating messages to authorized administrators. Visitors can submit new messages but cannot view or edit inbox entries.

4. Providers

  • GitHub: provides public release metadata and APK downloads, and hosts optional issue reports.
  • Supabase: stores support records and authenticates administrators.
  • GitHub Pages: hosts the public website.

5. Browser storage

Your browser stores language/theme preferences, a cached public release listing and a recent-submit timestamp. This version does not include advertising analytics. Hosting providers may process technical access logs under their own policies.

6. Retention and deletion

Messages are kept for the time needed to handle support and maintain a support history. No fixed automatic deletion schedule has been established. Request correction or deletion via the support form using the same email; ownership may need to be verified.

7. Security

HTTPS and Supabase row-level security are used. No online service can guarantee absolute security; avoid submitting sensitive information.

8. Android app privacy

App data practices for messages, media, calls, notifications and retention require a separate verified policy and are not described by this website notice.

9. Contact and updates

For requests regarding website data, use the support form. This notice may be updated with new features and providers, and its revision date will change accordingly.
