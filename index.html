QUESTIONS & ANSWERS

الأسئلة الشائعة

كيف أحمّل نايل شات؟

اضغط تحميل التطبيق، ثم افتح ملف APK الذي يتم تنزيله من GitHub. اتبع تعليمات أندرويد لتثبيت التطبيقات من هذا المصدر إن سمحت بذلك.

كيف أعرف أحدث إصدار؟

قسم التحديثات يحاول قراءة آخر إصدار منشور على GitHub تلقائياً. إذا تعذر الاتصال يعرض رابط الإصدار الاحتياطي المعروف.

هل الموقع نفسه تطبيق للدردشة؟

لا. هذا الموقع للتعريف بالتطبيق وتنزيله ومتابعة أخباره، بينما المحادثات تتم داخل تطبيق أندرويد.

هل أحتاج حساب GitHub لتحميل التطبيق؟

عادة يمكن تنزيل ملفات الإصدارات العامة دون حساب، لكن إرسال بلاغ من GitHub يحتاج إلى تسجيل الدخول.

PRIVACY & TRANSPARENCY

خصوصية موقع نايل شات

هذه المعلومات تخص الموقع التعريفي ونموذج التواصل؛ خصوصية تطبيق أندرويد موثقة بشكل منفصل بعد مراجعة إعداداته.

بيانات التواصل

عند إرسال رسالة دعم، نجمع الاسم والبريد الإلكتروني ونوع الرسالة وعنوانها ونصها لإدارة طلبك والرد عليه.

التخزين والوصول

تُحفظ الرسائل في قاعدة بيانات Supabase ويطّلع عليها مديرو الدعم المصرح لهم فقط. لا تُعرض الرسائل علناً على الموقع.

الخدمات الخارجية

يعرض الموقع بيانات تحديثات عامة من GitHub وقد ينقلك إليه لتنزيل التطبيق. يخزن متصفحك إعدادات المظهر واللغة وذاكرة مؤقتة لبيانات الإصدارات.

التواصل والحذف

يمكنك طلب تصحيح بيانات رسالتك أو حذفها عن طريق نموذج الدعم مع ذكر بريدك المستخدم. لا تضع كلمات مرور أو بيانات حساسة داخل الرسالة.
